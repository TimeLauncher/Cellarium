# A03~A06 Fix 반영 현황 (a03a06 브랜치)

> 2026-09-02 작성. 기획자에게 그대로 전달하는 텍스트.
> 기준 커밋 `bb06984` + 미커밋 수정분.

**된 것**

**1. 섭취 가능 몬스터에 대시 적중 판정 (B-1)**
체력 0인 몬스터는 대시 적중 대상에서 빼버렸습니다. 원래는 시체에 맞으면서 플레이어가 튕겨나가 대시가 끊겼는데, 이제 그냥 통과합니다. 섭취는 마우스 위치로 따로 잡는 거라 영향 없습니다. 별도 설정 없이 바로 적용됩니다.

**2. 셀 드랍 타일 이탈 (B-5)**
셀 덩어리가 물리 오브젝트가 아니라 직접 계산한 포물선으로 움직여서 벽을 그냥 통과하고 있었습니다. 위아래는 막혀 있었는데 좌우가 무제한이라 최대 1.4타일까지 뚫고 나갔습니다. 이제 벽에 닿으면 멈추고, 가로 이동도 1.2타일로 제한됩니다.
→ 인스펙터 `Cell Chunk`에 `Max Pop Distance X`(기본 1.2)가 생겼으니 튀는 거리는 여기서 조절하시면 됩니다.
→ **다만 낭떠러지 끝에서 잡으면 셀이 허공에 남는 건 그대로입니다.** 가로 벽만 막았습니다.

**3. 몬스터 공격 범위 상시 표시 (B-3)**
이건 원래 인스펙터 토글이 있었습니다. 기본값이 켜짐이었던 게 문제라 기본값을 끄고, 배치된 몬스터 30마리(A01 8, A02 8, SampleScene 7, SampleScene2 7) 값도 전부 껐습니다.
→ 다시 보고 싶으시면 몬스터의 `Monster Base` → `Show Hitbox` 체크하시면 됩니다.

**4. 일반비행균 돌진 모션 방향**
돌진 중에는 이동 처리가 통째로 건너뛰어져서 방향 잡는 코드가 아예 안 돌고 있었습니다. 돌진 시작 시점에 목표 방향으로 돌리게 했습니다. 설정할 것 없습니다.

**5. 세이브 선택창 ESC 복귀**
타이틀 복귀 기능 자체는 있었고 버튼에만 걸려 있었습니다. ESC 입력만 이어 붙였습니다.

**6. A06 병사 조기 소멸 (Bug Report에 없던 건)**
NPC 사라지는 기능이 "몇 번째 대사인지"만 보고 어떤 대화인지는 안 봐서, 병사 퇴장 대사(2줄)에선 발동 안 하고 뒤에 나오는 T세포 대사(5줄) 도중에 사라지고 있었습니다. 지정한 대화에서만 발동하도록 고쳤습니다.
→ `Npc Dialogue Disappear`에 `Target Dialogue` 칸이 생겼습니다. **이벤트로 재생되는 대사는 여기에 대화 에셋을 직접 넣어야 합니다.** NPC 상호작용으로 말 거는 경우는 비워두면 알아서 잡습니다. A06 병사 둘은 퇴장 대사로 이미 연결해뒀습니다.

**안 된 것**

- **B-4 이펙트 일자 범위** — Particle 씬 파티클 설정 쪽으로 보입니다. 에디터 작업일 가능성이 큽니다.
- **메인 타이틀 설정** — 설정 창은 이미 있고 화면도 스스로 만들어서 붙이는 건 쉬운데, 타이틀 메뉴가 다른 분 작업이라 겹칩니다. 기존 메뉴에 "설정" 한 줄 추가로 갈지 알려주세요.

**질문 주신 것 — 대시 공격 판정 레이어**
네, monster 레이어에 잡혀 있습니다. 정확히는 `monster 레이어` → `몬스터 스크립트 보유` 2단계를 다 통과해야 맞습니다. 배치된 몬스터 전수 확인했고(A01 11, A02 8, SampleScene 6, SampleScene2 6 + 프리팹 4종) 어긋난 건 없습니다. A03/A06은 몬스터가 아직 없습니다.
→ **주의**: 섭취 판정도 같은 레이어를 씁니다. 새 몬스터를 Default로 두면 대시뿐 아니라 섭취까지 통째로 무반응이 됩니다.

**개발시트 관련 — 레이어 순서는 건드리면 안 됩니다**
공격 판정이 레이어 이름이 아니라 순서(번호)로 저장돼 있습니다. 중간에 새 레이어를 끼우거나 순서를 바꾸면 저장된 번호가 밀리면서 전 씬에서 대시/섭취가 조용히 죽습니다.
- 이름만 바꾸는 건 안전 (monster → Monster 정도)
- 새 레이어(NPC, Item, Object, Event 등)는 **빈 자리 9번 이후에만** 추가
- Sorting Layer는 판정과 무관하니 자유롭게 정리하셔도 됩니다
