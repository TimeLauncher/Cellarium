## 기능 수정 사항

### (1) 이동 발판 — 벽 사이에 끼이는 문제

**한 일**: 발판만 고치는 대신, **화이트셀 쪽에 '끼임 탈출'을 붙였다**(`CrushEscape.cs`).
앞으로 추가될 이동 타일·이동 오브젝트·닫히는 문 무엇이든 자동으로 적용된다.

- 서로 반대쪽에서 미는 지형 두 개에 동시에 끼었을 때만 작동한다 (평소엔 물리 엔진에 맡긴다).
- 끼임 방향과 직각인 두 방향 중 **막혀 있지 않고 더 가까운 바깥쪽**으로 밀어낸다.
- 이동 발판은 예전처럼 "탈 사람이 천장에 눌릴 것 같으면 잠깐 멈춤"도 유지한다.
  → 발판이 멈춰 있는 동안 화이트셀이 옆으로 빠져나가고, 빠져나가면 발판이 다시 움직인다.

**인스펙터**: PC(`PC_WhiteCell`)의 PlayerController에 항목 2개.
- `Allow Crush Escape` (기본 켬) — 끄면 예전 동작
- `Crush Escape Speed` (기본 8) — 옆으로 밀려나는 속도(초당 타일). 답답하면 올리면 됨

### (2) 시야 제한 영역(EV_VisionArea) — 모양 고정 + 반듯한 외곽선

**한 일**: `VisionArea.cs`를 다시 썼다.

- **사각형 고정 해제**: 이제 붙어 있는 콜라이더 모양을 그대로 따라간다.
  기본은 여전히 사각형(Box Collider 2D)이고, **자유 형태로 만들려면 Box Collider 2D를 지우고
  Polygon Collider 2D를 붙이면 된다**(씬 뷰에서 Edit Collider로 점을 찍어 원하는 모양을 만들 수 있음).
  원형(Circle), 여러 타일을 묶은 Composite Collider도 지원한다. 오목한 모양도 된다.
- **외곽선 음영**: 경계에서 바깥으로 알파가 서서히 빠지는 띠를 붙여 블러/에어브러시처럼 보이게 했다.
  안쪽 암막(①)은 경계 바깥으로 흐려지고, 바깥 암막(③)은 경계에서 서서히 짙어진다.

**인스펙터**: EV_VisionArea 오브젝트의 VisionArea.
- `Edge Feather` (기본 1.2) — 흐려지는 폭(타일). **0이면 예전처럼 칼같이 잘린 선.** 2~3까지 올리면 더 뿌옇다
- 나머지(`Hide Until Entered`, `Reveal On First Entry`, `Darken Outside Inside`, `Outside Darkness`,
  `Fade Duration`, `Outside Extent`)는 예전과 같음

※ 바깥 암막(③)은 영역 모양을 바깥으로 밀어낸 형태로 만든다. 별·ㄹ자처럼 심하게 오목한 모양에서는
   바깥 암막이 어긋날 수 있으니, ③을 쓰는 구간은 볼록한 형태로 잡는 걸 권장.

### (3) 비행균 둥지(OBJ_FlyingGermNest)

- **소환 직후 행동 지연**: 소환된 몬스터가 바로 공격하지 않는다. **이동·추적은 그대로 하고 공격만 막는다**
  (문서의 "이동을 제외한 행동" 그대로).
- **소환된 몬스터는 셀을 드랍하지 않는다**: 요청대로 둥지가 소환할 때 셀 드랍을 꺼서 내보낸다.
  프리팹 원본은 건드리지 않으므로, 맵에 직접 배치한 같은 몬스터는 정상적으로 셀을 떨군다.

**인스펙터**: 둥지 오브젝트의 MonsterNest에 항목 2개.
- `Spawn Action Delay` (기본 1초) — 소환 후 공격을 시작하기까지의 시간
- `Spawned Monsters Drop Cells` (기본 끔) — 켜면 소환 몬스터도 셀을 떨군다

## Bug Report — 화이트셀 중력값

**원인**: 조종 중인 화이트셀에만 추가 중력 보정(Fall/Low Jump/Ascend Multiplier)이 걸려 있었고,
비조종 화이트셀·던져진 분열체는 **기본 중력만** 받고 있었다. 그래서

- 조종 중일 때보다 천천히 떨어지고(= 중력값이 다름),
- 아래에서 밀어 올리면 상승 속도가 전혀 깎이지 않아 위로 붕 떴다
  (아래 화이트셀이 위로 대시 / 버튼 발판이 빠르게 상승하는 경우).

**한 일**: 중력 보정을 한 함수로 합쳐서 **조종 여부와 상관없이 같은 값**을 쓰게 했다.
비조종 상태는 '점프 키를 누르지 않은 것'으로 처리하므로 `Low Jump Multiplier`가 상승을 빠르게 죽인다
→ 밀어 올려도 붕 뜨지 않는다.

※ 의도적으로 띄우는 연출(넉백 포물선)은 예전대로 유지된다.
