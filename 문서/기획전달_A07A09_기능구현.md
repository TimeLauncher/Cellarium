[A07~A09 기능 추가 반영 현황] (2026-09-17, 코드 기준 / 씬 배치 전)

■ 된 것 (코드 완료, 씬에는 아직 안 놓음)
(1) 이동 발판 TL_MovingPlatform — 버튼 여러 개 연결 가능(하나라도 눌리면 이동, 모두 떼면 복귀)
(2) 혈류 OBJ_BloodFlow — 상하좌우 흐름 / 방향키로 방향 지정 후 점프로 이탈 / 대시 가능, 역류 방향은 막힘 / 버튼으로 흐름 반전(추후 기능이라고 하셨던 것 미리 넣음)
(3) 시야 제한 영역 EV_VisionArea — ①들어오기 전까지 까맣게 ②첫 입장 후 영구 해제 ③안에 있을 때 바깥을 어둡게, 셋 다 On/Off 가능 + "벽 부서질 때만 해제" 옵션
(4) 비행균 둥지 OBJ_FlyingGermNest — 소환 몬스터/주기/주기당 수량/셀 드랍량 지정, 파괴 후 재생성 안 됨
(5) 응고 조직 벽 OBJ_CoagulatedWall — 대시로 부숨, 재생성 안 됨, 부서지면 연결한 시야 제한 영역 해제
(6) 수축 조직 타일 TL_PulseFloor — 밟은 뒤 꺼질 때까지 시간 / 다시 생길 때까지 시간 조절 가능
(7) 거미줄 바닥 TL_SpiderWeb — 이동속도·점프·대시거리 감소, 닿아 있는 동안 유지, 벗어나고 1초 뒤 해제
+ 상단/하단 지역 진입 연출 — 입장 지점마다 "걸어 나오기 / 아래에서 뛰어올라 착지 / 위에서 떨어져 착지" 선택

■ 확인 부탁드릴 것
1. 수치는 전부 임시값입니다. QA하면서 알려주시면 맞추겠습니다.
   - 거미줄: 이동 0.5배 / 점프 0.7배(높이는 약 절반) / 대시거리 0.5배 / 벗어난 뒤 1초 유지
   - 혈류: 흐르는 속도 8 / 이탈 속도 10 / 이탈 후 0.35초 동안 다시 안 빨려 들어감
   - 수축 타일: 밟고 0.5초 뒤 꺼짐, 2초 뒤 복구
   - 둥지: 체력 200 / 5초마다 1마리 / 최대 3마리 동시 / PC가 12칸 안에 있을 때만 소환 / 파괴 시 셀 50(10덩어리)
   - 응고 벽: 체력 100 (현재 A00 플레이어 대시 공격력 50 → 2번에 파괴)
2. 둥지 "최대 동시 수"와 "PC 근처일 때만 소환"은 기획서에 없던 것입니다. 없으면 비행균이 무한히 늘어나서 넣었는데, 원하시는 규칙 있으면 알려주세요.
3. 둥지·벽을 때리는 수단은 지금 "대시 공격" 하나입니다(몬스터와 동일). 다른 공격으로도 부서져야 하면 알려주세요.
4. 파괴된 벽/둥지, 해제된 암시야는 죽어도 되돌아오지 않게 해뒀습니다(세이브 전으로 되돌리려면 설정 가능).
5. 혈류 안에서 S+Space는 내려찍기가 아니라 아래 방향 이탈로 동작합니다.
6. 암시야는 검은 사각형으로 임시 표시됩니다. 전용 아트/그라데이션이 필요하면 리소스 부탁드립니다.
7. 개발시트 이름 기준으로 컴포넌트 이름이 조금 다릅니다: 비행균 둥지 = MonsterNest(아무 몬스터나 소환 가능한 공용 둥지), 나머지는 시트 이름과 같습니다.

■ 배치 방법 (인스펙터)
공통: 빈 오브젝트 → 스프라이트 → 컴포넌트 추가. 오브젝트 이름은 개발시트대로(OBJ_BloodFlow1 등).

[이동 발판] Box Collider 2D + Rigidbody 2D + MovingPlatform
 - Activators: 연결할 버튼(OBJ_Button)들을 드래그 (여러 개 가능)
 - Destination Offset: 이동할 거리(x, y). 선택하면 하늘색 선으로 도착 위치 표시
 - Speed: 이동 속도

[혈류] Box Collider 2D + BloodFlow (한 구간 = 오브젝트 1개)
 - Flow Direction: Right/Left/Up/Down
 - 꺾이는 길은 구간 여러 개를 모서리가 겹치게 이어 붙이기
 - Flow Speed / Exit Speed / Exit Immunity: 위 수치
 - Reverse Activators: 흐름을 뒤집을 버튼(비우면 반전 없음)
 - 씬 뷰에 빨간 박스 + 화살표로 방향 표시

[시야 제한 영역] Box Collider 2D + VisionArea (박스 크기 = 가릴 범위)
 - Hide Until Entered: ① 들어오기 전 까맣게
 - Reveal On First Entry: ② 한 번 들어오면 영구 해제 (끄면 나갈 때마다 다시 가려짐)
 - Darken Outside Inside: ③ 안에 있을 때 바깥 어둡게 / Outside Darkness로 진하기
 - Reveal Only By Trigger: 켜면 들어가도 안 풀리고 벽이 부서져야만 풀림 (응고 벽 뒤 공간용)

[응고 조직 벽] Box Collider 2D(Is Trigger 끔) + CoagulatedWall
 - 레이어: Ground 또는 Wall (Monster 레이어에 두면 PC가 통과함)
 - Max Hp, 셀 드랍(Cell Drop Total/Count)
 - Reveal On Break: 벽 뒤의 시야 제한 영역 드래그 (그 영역은 Reveal Only By Trigger 켜기)

[비행균 둥지] Collider 2D + MonsterNest
 - Spawn Prefab: MS_Germ_Flying 프리팹
 - Spawn Interval / Spawn Per Wave / Max Alive / Activation Range
 - Max Hp, Cell Drop Total/Count (컴포넌트 붙이면 체력 200, 셀 50/10개로 자동 설정)

[수축 조직 타일] Box Collider 2D + PulseFloor
 - Collapse Delay: 밟고 꺼질 때까지 / Restore Delay: 다시 생길 때까지

[거미줄 바닥] Box Collider 2D + SpiderWeb
 - Linger Duration: 벗어난 뒤 유지 시간
 - Move / Jump / Dash Multiplier: 감소 배율 (1 = 감소 없음)

[상하단 진입 연출] 기존 입장 지점(SceneEntryPoint)에서
 - Arrival Style: Walk(옆 입구) / JumpUp(상단 지역 진입 — 아래에서 뛰어올라 착지) / FallDown(하단 지역 진입 — 위에서 떨어져 착지)
 - JumpUp: Jump In Depth(얼마나 아래서 시작) / Jump In Side Offset / Jump In Velocity
 - FallDown: Fall In Height(얼마나 위에서 시작)
 - 선택하면 하늘색 박스로 시작 위치가 보임 → 반드시 뚫린 통로 안에 있어야 함(벽/바닥 속이면 끼임)
