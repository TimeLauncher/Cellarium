## 기능 추가

### (1) 파괴형 작동장치 — 신경 다발 / 신경 조직

대시로 때려 체력을 0으로 만들면 부서지면서, 버튼과 똑같이 연결된 장치를 작동시킵니다. 한 번 부서지면 다시 생기지 않습니다(죽어도·씬을 다시 들어와도 유지).

**배치**: 오브젝트에 Collider2D(크기 = 맞는 범위) + `DestructibleActivator` 컴포넌트
- `Max Hp` — 체력
- `Blocks Player` — 켜면 길을 막는 몸체(신경 다발). 끄면 지나다닐 수 있는 배경(신경 조직), 대시로는 맞음
- `Destroyed Sprite` — 부서진 뒤 이미지. 비우면 부서지면 사라짐
- 연결: 문의 `Required Buttons`, 이동 발판의 `Activators`, 혈류의 `Reverse Activators`, 낙하 혈전의 `Activators` 칸에 이 오브젝트를 넣으면 됩니다. (문 칸에 이제 버튼 말고 다른 장치도 들어갑니다)

### (2) 보스 게이트 OBJ_BossGate

A11·A13의 심장 결절이 둘 다 활성화되면 사라지는 문입니다. 다른 씬의 결절 상태를 읽습니다. 기획서대로 열리는 연출은 없고 조건이 차면 그냥 사라집니다.

**배치**: 게이트 오브젝트에 `BossGate` 컴포넌트
- `Required Nodes` — 기다릴 결절 이름 (기본 LeftHeartNode, RightHeartNode). 결절의 `Node Key`와 똑같이 적어야 함
- `Open Mode` — Hide: 조건이 차면 게이트를 끔 / Event Only: 끄지 않고 `On Ready`만 호출 (나중에 '혈류 역류로 게이트 파괴' 연출을 붙일 때 이걸로 바꾸고 연출이 게이트를 없애게)
- `On Ready` — 조건이 처음 찼을 때 호출할 것 (연출 연결용)

**배경 변화용** (결절 1개 활성 시 A09 좌측 배경에 혈류 등): 빈 오브젝트에 `HeartNodeStateObject`
- `Watch Nodes` — 볼 결절 이름 / `Required Count` — 몇 개 이상이면 충족인지 (0 = 전부)
- `Show When Met` — 충족되면 켜질 오브젝트들 / `Hide When Met` — 충족되면 꺼질 오브젝트들
- 연출 장면 자체는 이벤트 기능으로 따로 만들고, 이건 '연출이 끝난 뒤 상태'를 맞추는 용도입니다.

### (3) 낙하 혈전 OBJ_FallingClot

연결된 장치가 켜지면 잠깐 흔들린 뒤 빠르게 떨어지며, 지나가는 자리의 몬스터·PC·부서지는 오브젝트에 피해를 주고 바닥에 닿으면 사라집니다. 한 번 떨어지면 다시 생기지 않습니다.

**배치**: 천장 위치에 놓고 Collider2D(크기 = 피해 범위) + `FallingClot`
- `Activators` — 이 중 하나라도 켜지면 떨어짐 (버튼, 신경 다발 등)
- `Fall Delay` (0.3초) / `Shake Amount` — 떨어지기 전 흔들림
- `Start Speed` 6 / `Acceleration` 60 / `Max Speed` 30 — 낙하 속도
- `Monster Damage` 100 / `Player Damage` 50 / `Object Damage` 100 — 몬스터·PC·오브젝트 피해 따로
- 씬에서 선택하면 떨어질 경로가 빨간 박스로 보입니다.

### (4) 심장 결절 OBJ_HT_LeftHeartNode / OBJ_HT_RightHeartNode

대시로 체력을 0으로 만들면 코어가 드러나고, 코어를 섭취하면 활성화됩니다. 코어는 사라지고 결절은 활성화된 이미지로 계속 남습니다(씬을 바꿔도, 죽어도 유지).

**배치**: 5x5 결절 오브젝트에 Collider2D + `HeartNode`, 코어(2x2 스프라이트)는 자식 오브젝트로
- `Node Key` — **왼쪽은 LeftHeartNode, 오른쪽은 RightHeartNode** (보스 게이트가 이 이름으로 찾음)
- `Core` — 자식 코어 오브젝트 연결. 처음엔 자동으로 숨겨지고, 섭취 판정(콜라이더·레이어)도 자동으로 붙음
- `Max Hp` — 체력
- `Broken Sprite` — 체력 0, 코어 드러난 상태의 이미지 (선택)
- `Activated Sprite` — 활성화된 뒤 이미지
- `Core Heal Hp / Core Heal Gauge` — 코어 섭취 시 회복량 (기본 0)
- `On Activated` — 활성화 순간 호출 (결절 활성화 연출, A09 혈류 연출 연결용)

### (5) 몬스터 웨이브

영역에 들어가면 시작 → 출입구가 닫히고 → 웨이브마다 지정한 몬스터가 지정 위치에 생성 → 전부 잡으면 대기 후 다음 웨이브 → 마지막까지 끝나면 출입구가 열리고 완료가 저장됩니다(다시 안 나옴). 웨이브 몬스터는 셀을 떨구지 않습니다. 싸우다 죽으면 처음부터 다시 합니다.

**배치**: 빈 오브젝트 + BoxCollider2D(시작 영역 크기) + `MonsterWave`
- `Waves` — A. 웨이브 개수만큼 칸을 늘림
  - `Monsters` — B. (몬스터 프리팹, 생성 위치) 를 원하는 만큼. 생성 위치는 빈 오브젝트를 놓고 연결
  - `Spawn Action Delay` (1초) — B. 생성 후 행동하기까지 시간 (둥지와 같은 방식)
  - `Delay Before Next` (2초) — C. 이 웨이브를 다 잡고 다음 웨이브까지 대기
- `Start Delay` (0.5초) — 영역 진입 후 첫 웨이브까지
- `Gates` — 웨이브 중 길을 막을 벽 오브젝트들 (시작 전엔 자동으로 꺼짐)
- `On Started / On Completed` — 연출 연결용

## 몬스터 수정

### 전체 몬스터 공통 (모든 몬스터 인스펙터에 생김)

- **순찰/추적 속도 분리**: `Separate Chase Speed` 켜면 추적할 때 `Chase Speed`, 순찰은 `Move Speed`. 끄면 둘 다 Move Speed (기존과 같음). 비행균은 원래대로 항상 Chase Speed로 추적
- **PC 인지 정지**: `Notice Duration` — 순찰 중 PC를 처음 발견하면 이 시간 동안 이동·공격 없이 멈춤 (기본 0 = 기존과 같음). 모션·사운드를 붙일 자리로 `Notice Trigger`(애니메이터 트리거 이름, 기본 Notice)와 `Notice Sound`도 있음
- **추적 유지**: `Chase Memory Time` — 시야 밖으로 나가도 이 시간 동안은 계속 쫓다가 순찰로 복귀 (기본 0 = 즉시 복귀)
- **후딜레이**: `Post Attack Pause`는 공격이 하나뿐인 몬스터의 '그 공격의 후딜레이'입니다. 공격이 여러 개인 거미균·침식 거미균은 공격마다 `Recovery` 값이 따로 있고 이 값은 안 씁니다
- **Turn Pause Duration**: 이제 모든 몬스터(거미균·소형거미균·부유균 포함)에 적용. 0이면 작동 안 함
- 새로 넣는 값들은 기본이 '기존과 같음'이라, 이미 배치된 몬스터는 값을 넣기 전까지 그대로입니다.

### (1) 거미균

- **순찰이 안 되던 원인**: 몸 콜라이더가 커서 벽·바닥에 '붙었다'는 판정이 영영 안 나서 이동을 아예 안 하고 있었습니다. 수정 → 이제 순찰·추적 이동을 하고, 바닥이면 좌우, 벽이면 상하로 순찰합니다 (`Fit Body To Surface` 켜짐이 기본)
- **덮치기**: 시전 순간 PC가 있던 자리 **아래 바닥**으로 착지합니다(공중·벽·천장에 붙지 않음). 착지 후엔 바닥에서 다닙니다. 준비시간(`Pounce Windup`)·후딜레이(`Pounce Recovery`)가 이제 실제로 적용됩니다
- **베기**: 침식 거미균과 같은 방식. 앞쪽 박스 범위 `Slash Box Size / Slash Box Offset`로 크기·위치 조절, `Slash Windup` 준비시간, `Slash Recovery` 후딜레이 (베기 직후 바로 덮치기 하던 문제 해결)
- 쿨타임은 공격이 끝난 뒤부터 돕니다. 범위는 반투명 판으로 표시 (`Show Attack Areas`)
- **수치**: 베기 쿨 2.5 / 덮치기 데미지 50 / 덮치기 범위 1 / 체력 300 — 새로 붙이는 거미균의 기본값으로 넣었습니다. **이미 배치된 거미균은 인스펙터에서 직접 바꿔 주세요** (또는 컴포넌트 ⋮ > Reset)

### (2) 소형거미균

- `Align Tolerance` (기본 1) — 벽을 따라가는 축에서 PC와 차이가 이 값 안이면 멈춤 (PC Y 10 → 9~11에서 정지). 0이면 예전처럼 정확히 따라옴

### (3) 비행균

- `Keep Distance` (기본 켬) — PC에게 끝까지 붙지 않고 거리를 둠
- `Keep Distance Range` n (기본 3) — 이 거리까지만 다가오고, 더 가까워지면 바깥으로 물러남. **돌진 사거리(Dive Attack Range)보다 크면 돌진을 못 하니 같거나 작게**
- (실험) `Wander In Band` (기본 켬) — n~a 사이에선 다가오지 않고 그 범위 안을 돌아다님. 끄면 n 거리에서 떠 있음
- `Wander Outer Range` a (기본 6) / `Wander Retarget Interval` (1.2초) / `Wander Speed` (0이면 Move Speed)

### (4) 침식 거미균

- **다크셀 분출 투사체**: `Dark Burst Random Arc` 켜면 투사체마다 `Dark Burst Arc Height`(포물선 높이 최소~최대, 기본 2~6)와 `Dark Burst Fall Speed`(떨어지는 속도 배율 최소~최대, 기본 0.7~1.4)를 랜덤으로. `Dark Burst Min Spacing`(기본 1.5) — 떨어지는 지점끼리 최소 간격
- **촉수 뻗기 범위**: `Tentacle Reach`(앞), `Tentacle Back Reach`(뒤), `Tentacle Height`(세로), `Tentacle Box Offset`(이동 — 아래로 내리려면 Y 음수). 씬에서 선택하면 범위가 박스로 보임
- **벽면 이동**: 직선으로 날아가지 않고 바닥을 걸어서 벽 밑까지 간 뒤 벽을 타고 올라감. `Wall Move Walk Speed`(걷기, 9) / `Wall Move Speed`(벽 타기, 14)
- **회복 오브젝트**: 체력이 `Heal Drop Every Hp Lost`(기본 450)만큼 깎일 때마다 주변 바닥(`Heal Drop Radius` 6 안) 무작위 위치에 위에서 떨어짐. 섭취하면 체력 `Heal Drop Amount`(100) 회복. `Heal Drop Prefab`을 비우면 초록 동그라미로 임시 표시

- **분열체 전환 시 카메라 고정**: A00이 아닌 씬에서 바로 Play하면(개발용 자동 플레이어 생성) 카메라 연결이 비어 있어서 생기는 문제를 찾아 고쳤습니다. A00부터 정상 진행했을 때도 생기면 어느 씬이었는지 알려주세요

- **화이트셀 접촉 콜라이더 원형 → 사각형**: A00·TEST_Gimmick·개발용 플레이어 프리팹의 PC_WhiteCell 몸통을 BoxCollider2D(1.34 x 1.34, 기존 원과 같은 크기)로 바꿨습니다. 크기는 PC_WhiteCell의 Box Collider 2D(Is Trigger 꺼진 쪽)에서 조절
  - ⚠ 사각 콜라이더는 대시할 때 몸을 기울이면 지형에 끼어서, 대시 기울기 연출이 꺼집니다. 다시 쓰려면 스프라이트를 자식 오브젝트로 분리해 PlayerController `Dash Visual Root`에 연결해야 합니다 (애니메이션 경로도 같이 바뀌어야 해서 아트/애니 작업과 같이 해야 함)
- **대시 넉백**: Dash Knockback Speed 18 / Up Ratio 1 (A00·TEST_Gimmick·개발용 프리팹 + 코드 기본값)
