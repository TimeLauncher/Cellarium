A07~A09 기능 테스트 체크리스트 (2026-09-17)

준비
[ ] Unity 켜서 콘솔 빨간 에러 0 확인 (새 .cs의 .meta 생성됨)
[ ] 테스트 씬에 각 기믹 1개씩 배치 (A00에서 시작하거나, 테스트 씬에 PC 직접 배치)

거미줄 (SpiderWeb)
[ ] 닿으면 걷기가 느려짐 / 점프가 낮아짐 / 대시 거리가 짧아짐
[ ] 계속 닿아 있으면 계속 느림, 벗어나고 1초 뒤 원래대로
[ ] 거미줄 두 개가 겹쳐도 더 느려지지 않음
[ ] 분열 대시도 짧아짐

혈류 (BloodFlow)
[ ] 닿으면 가운데로 빨려 들어가 흐름 방향으로 이동 (좌/우/상/하 각각)
[ ] 안에서 좌우 이동키로 캐릭터가 움직이지 않고 방향만 바뀜
[ ] 방향키 없이 Space → 가로 흐름은 위로, 세로 흐름은 바라보는 쪽으로 튀어나감
[ ] ←/→/↑/↓(W,S 포함) 누른 뒤 Space → 마지막 방향으로 튀어나감
[ ] S+Space가 내려찍기 대신 아래 이탈로 나감
[ ] 흐름 방향 대시 OK / 역방향 대시는 안 나감 / 대각선 역방향은 흐름 성분이 빠진 채 나감
[ ] ㄱ자로 겹친 구간에서 자연스럽게 꺾임
[ ] 이탈 직후 바로 다시 빨려 들어가지 않음
[ ] 분열체(조종 안 하는 것)도 떠내려감
[ ] Reverse Activators에 버튼 연결 → 버튼 누르면 흐름 반대
[ ] 혈류 안에서 피격 / 사망 / 부활 시 이상 없음

이동 발판 (MovingPlatform)
[ ] 버튼 누르면 도착 위치로 이동, 떼면 복귀
[ ] 버튼 2개 연결 → 둘 중 하나만 눌러도 이동
[ ] 발판 위에 선 채로 같이 이동 (미끄러지지 않음)
[ ] 올라가다 천장에 PC가 끼면 발판이 멈춤 (PC 안 끼임)

수축 조직 타일 (PulseFloor)
[ ] 밟고 0.5초 뒤 반투명해지며 떨어짐
[ ] 2초 뒤 복구, PC가 겹쳐 있으면 빠져나갈 때까지 복구 안 됨

시야 제한 영역 (VisionArea)
[ ] ①만 켬: 들어가기 전 까맣고, 들어가면 풀림
[ ] ①+② 켬: 나왔다가 다시 봐도 계속 풀려 있음 / 죽고 부활해도 풀려 있음
[ ] ①만 켜고 ② 끔: 나오면 다시 까매짐
[ ] ③ 켬: 안에 있을 때 바깥이 어두워지고 나오면 원래대로
[ ] 암막이 캐릭터·타일·배경보다 위에 그려짐 (UI보다는 아래)
[ ] 분열체만 들어갔을 때는 반응 안 함 (조종 중인 캐릭터 기준)

응고 조직 벽 (CoagulatedWall)
[ ] 벽이 PC를 막음 (통과 안 됨)
[ ] 대시로 치면 이펙트 + 붉게 깜빡 + 튕겨나옴
[ ] 체력 0 되면 사라지고 셀 드랍 (설정한 경우)
[ ] Reveal On Break에 연결한 영역의 암시야가 풀림
[ ] 죽고 부활 / 씬 재진입해도 벽이 다시 안 생김
[ ] 벽에 붙어서 벽타기·지면 판정이 이상하지 않음

비행균 둥지 (MonsterNest)
[ ] PC가 가까이 가면 1초 뒤부터 5초마다 비행균 소환
[ ] 최대 3마리에서 멈추고, 잡아서 시체가 되면 다시 소환
[ ] 멀어지면 소환 멈춤
[ ] 대시로 파괴 → 즉시 사라지고 셀 대량 드랍, 먹으면 재화 증가
[ ] 부활 / 씬 재진입해도 둥지 다시 안 생김
[ ] 소환된 비행균이 정상적으로 추적·돌진함

상하단 진입 연출 (SceneEntryPoint)
[ ] JumpUp: 화면이 밝아진 뒤 아래에서 뛰어올라 도착 지점에 착지, 그동안 조작 불가
[ ] FallDown: 위에서 떨어져 착지 후 조작 가능
[ ] 진입 중 포털이 다시 발동하지 않음 (왔던 씬으로 안 튕김)
[ ] 카메라가 튀지 않음
[ ] 기존 Walk 입장 지점 동작 그대로

회귀 확인
[ ] 일반 점프/벽점프/대시/분열 대시/내려찍기 수치가 예전과 동일 (기믹 밖에서)
[ ] 몬스터 대시 공격·섭취 이상 없음
[ ] 타이틀 → 새 게임 시 이전 판 체력·재화가 딸려오지 않음 (메뉴 씬 저장 방지)
